# Security policy

## Reporting a vulnerability

Report vulnerabilities in any LM-Kit product to **security@lm-kit.com**. Please do not open a
public issue: a report that reaches the tracker reaches everyone at once, before a fix exists.

A useful report names the product and version (the `Help` footer of the admin panel, or
`lmkit version` on the command line), the deployment shape (host install, container, cluster),
the steps that reproduce the problem, and its impact as you understand it. Encrypting the report
is welcome; ask us for a key at the same address if you want one.

We acknowledge every report, keep you informed while we work on it, and credit you in the release
notes of the fix unless you prefer otherwise.

## Supported versions

The latest release of each product is the supported one. Fixes ship as a new release; nothing is
back-ported to an earlier version, so staying current is the way to stay covered.

## Where security is documented

The security model, the threat model and the review material for LM-Kit One are part of its
guides at https://docs.lm-kit.com/lm-kit-one.
